# Rapportbilder

Lägg publiceringsgodkända bilder, kartbilder och statiska figurer här.
Referera till dem från kapitlen med en relativ sökväg, exempelvis
`../assets/images/figur.png`. Ange bildtext, källa och beskrivande alternativtext.

`rapporthuvud.svg` är originalet till sidhuvudets illustration.
`stadssiluett.svg` innehåller endast siluetten, utan den gamla texten och logotypen.
