# Återanvändbar diagramkod

Här lägger vi gemensam JavaScript för diagram, filter och tabellvyer när den
första figuren byggs. Börja gärna med en OJS-chunk i ett kapitel och flytta
gemensam kod hit när flera figurer behöver den.

Chart.js, D3 eller Observable Plot väljs efter figurens behov. Inga bibliotek
hämtas eller laddas i startmallen.
